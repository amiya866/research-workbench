02 / PIPELINE

研究管线

总纲五层契约 · 每次任务全链路执行
① 数据层
指标白名单内批量取数：iFinD 主连日线（13 品种分 5 批，显式日期，失败重试 1 次跳过）；LME / 美债 / TIPS / DXY / 产业库存 TC 排产——联网检索逐条引用，逐条标数据日。
② 分项分析层
宏观 / 利率 / 供需 / 库存 / 成本 / 跨品种分维度诊断；多空共用同一事实基础；缺口标注降权不忽略。
③ 合成裁决层
regime 动态权重 + 逐维度对冲 + 主导矛盾识别 + 分时间维度方向；观点稳定性：短期不跨零直翻，中期反转需三门槛（主导矛盾切换 / 硬数据证伪 / 关键结构突破）。
④ 编排产出层
日报九段式（今日三变 / 主要矛盾 / 尾部雷达 / 裁决表 / 宏观速读 / 品种点评 / 配置校验 / 指标总表 / 事件闭环＋事前冻结）；去 Agent 化写作，数字必须有来源。
⑤ 决策冻结层
decision_cutoff 事前冻结：每个判断带期限 / 成功条件 / 失败（失效）条件 / 重估节点；破证伪位旧方向作废，失效组合明示不默撤。

04 / DISCIPLINE

硬约束

任何产出不得违反 · 产出前自查
R1

数字必须有来源。行情=iFinD；LME/宏观/产业=联网检索逐条引用；禁编造，逐条标数据日。

R2

观点稳定性。短期不跨零直翻；中期反转需三门槛之一；失效按纪律明示「已失效」。

R3

证伪校验。每个判断带证伪位；价格破位旧方向作废，转中性或反手。

R4

数据缺口纪律。先刷新再降级；缺口标灰、不分配权重、不合成总分。

R5

实物门禁。商品方向必须回到库存 / 基差 / 月差 / 进口盈亏 / 持仓 / 订单 / 现货需求。

R6

去 Agent 化。不堆形容词，不出现流程黑话；结论可被证伪，叙事不单独支撑方向。
